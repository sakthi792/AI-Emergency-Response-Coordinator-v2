# AI Emergency Response Coordinator 🚨

An AI-powered multi-agent emergency response coordination system that analyzes emergency situations and generates intelligent response plans using Large Language Models (LLMs).

## Overview

The system is designed to support emergency response coordination by analyzing incoming emergency information and assigning the situation to specialized AI agents.

### Key Features

- 🚨 Emergency situation analysis
- 👮 Police response coordination
- 🚑 Ambulance response coordination
- 🚒 Fire response coordination
- 🏥 Hospital recommendation
- 🤖 LLM-powered decision making
- ⚡ FastAPI backend
- 💻 React-based frontend

## Tech Stack

- **Python**
- **FastAPI**
- **React**
- **Vite**
- **Tailwind CSS**
- **Large Language Models (LLMs)**
- **REST API**
- **Git & GitHub**
